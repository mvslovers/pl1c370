# plscorpus — measurement scripts for the PL/S corpus

Read-only scripts behind the numbers in `../local_corpus.md` and `../report.md`.
They scan the pristine IBM tree `~/repos/mvs/mvs38-ibmsrc` (path set in
`scan.py`, `ROOT`) and never write into it.

| File | Does |
|---|---|
| `scan.py` | classifies every member (PL/S output or not, layout A/B/C, IDR, statement numbers) and writes `scan.tsv` next to itself |
| `stats.py` | summary figures from `scan.tsv`; writes `pls_ibm.txt` and `pls_var.txt` |
| `an1.py` … `an3.py` | follow-up breakdowns from `scan.tsv` |
| `pls_ibm.txt`, `pls_var.txt` | the PL/S members found in `ibm/` and `variants/` |
| `purepls.txt` | members that are PL/S source proper, not compiler output |

`scan.tsv` is not committed (1.5 MB, regenerated by `python3 scan.py`).

**Measurement rule.** Count over raw bytes (Python) or with
`LC_ALL=C /usr/bin/grep`. In the maintainer's shell `grep` is a function that
silently skips files containing X'AC' (the PL/S `¬`): it reported 415 files with
`%GOTO` where there are 495, and 37 `PL/S-II` IDRs where there are 127.
