# PL/S documents online and non-IBM PL/S tooling

Scope: an inventory of BSL / PL/S / PL/S II / PL/S III / PL/AS / PL/X documents that can be found online today, plus tools outside IBM. Research date 2026-10-12.
Every bitsavers PDF listed below was downloaded to
`a local download directory (PDFs not committed; URLs in the text)` and converted with pdftotext. The quotes come from those text files. The bitsavers search used a grep over `https://bitsavers.org/pdf/IndexByDate.txt` (93,688 lines) and the two directory listings `pdf/ibm/360/pls/` and `pdf/ibm/360/bsl/`. Those two directories hold **8 files in all**. A case-insensitive grep of the whole index (no truncation, restricted to `ibm/` paths, pattern `pl_?s[^a-z]|pl-s|/pls|bsl|pl_as|plas|pl_x|plx|Systems_Lang`, with plus/apl hits removed) returns exactly those 8 lines, so bitsavers has no other file with PL/S, BSL, PL/AS or PL/X in its name. File names only: a PL/S mention inside some other manual would not show up.
A sibling note, `pls_history_availability.md`, covers lineage, version history and IDR statistics. This file covers documents and tools.

## 1. Which IBM PL/S-family documents are findable online (inventory)

### Takeaway
Seven IBM documents are freely downloadable, all on bitsavers: two public "Guide to … Listings" books for PL/S and PL/S II, and five BSL documents that were once "IBM Confidential". Among them is a full BSL language specification and a user's guide with a chapter on compiler-generated code. I found no PL/S or PL/S II language reference, no programmer's guide, and nothing at all for PL/S III, PL/AS or PL/X anywhere online. The closest thing to a PL/S II language reference is the third-party Rand RL/S Language Reference Manual (archive.org; see section 3).

### Inferences
- The sources split cleanly into two groups. **The language definition** is the BSL Language Specification, plus the TNL, plus the RL/S manual for PL/S II-level syntax. **Code generation and conventions** come from the BSL User's Guide sections 5 and 6, from the two "Guide to … Listings" books (register assignments, save areas, generated labels, the GENERATE statement, listing formats), and above all from the hundreds of PL/S II-compiled MVS 3.8j modules. These carry the source as comments next to the code IBM generated, so they form a parallel corpus.
- The maintainer's "few documents" are very likely the bitsavers PL/S II guide and the BSL set. If he has anything else, such as a PL/S II language reference, it would be the only copy known to be outside IBM. Worth asking.
- BSL is a predecessor and not identical to PL/S II. PL/S II added AUTODATA and other options, and its listings use a different format. The BSL spec has to be read together with the PL/S II guide and RL/S.

## 2. Has anyone outside IBM built a PL/S compiler, translator, decompiler or other tool?

### Takeaway
There are two historical full compilers outside IBM. **Rand RL/S** (1975–77, XPL-based, PL/S II-compatible) was never distributed and its compiler source is not online. The **Fujitsu** PL/S compiler (late 1970s) was derived from IBM's PL/I Optimizer and not available outside Fujitsu and its affiliates. For MVS 3.8j there is only one small public-domain tool, the Perl script `pls-split`. A 2026 GitHub project, ZDoc, documents PL/X and PL/AS source. I found no open-source PL/S compiler, PL/S-to-C translator or PL/S decompiler.

### Cited Findings
- **Rand RL/S**, Rand Computation Center, Santa Monica. Built by R. Lawrence Clark, James S. Reiley and team leader David J. Smith with the XPL compiler-generator system. Described as "fully compatible with IBM's PL/S II language", built "using only publicly available, non-copyrighted PL/S documentation and PL/S source and generated assembler code examples from IBM distributed source files for the MVS operating system". Announced at SHARE in August 1976. IBM claimed the language was proprietary, and Rand agreed not to distribute the compiler. — [Wikipedia](https://en.wikipedia.org/wiki/IBM_PL/S)
- The RL/S manual (R-1555/11, August 1975, revised July 1977; copyright Rand) calls itself "a complete specification of the syntax and semantics as processed by version 2.8 of the RL/S compiler". It also states: "The assembler language code produced by the RL/S compiler is not identical to the code produced by the proprietary IBM PL/S compiler, but it is our intention that the two be functionally equivalent", and "The RL/S compiler is a proprietary product of The Rand Corporation". Its compiler tools came from "David Martin of UCLA and Franklin DeRemer of UCSC" (DeRemer is the LALR originator). Appendices: A default/conflicting attributes; B generated labels; C storage-class addressing patterns; D overview of generated code; E syntax summary; F programming example; G all diagnostic messages. — [archive.org RL/S manual](https://archive.org/details/rand-rl-s-language-reference-manual-1977) (PDF 25 MB + OCR text; uploaded 2023-03-29 by `dvdsmith@computer.org`, presumably David J. Smith; the item has no stated license)
- That uploader's only other archive.org item is the Rand WYLBUR Command Facilities manual. **No RL/S compiler source or binary is online.** — [archive.org uploader search](https://archive.org/advancedsearch.php?q=uploader%3A%22dvdsmith%40computer.org%22&fl%5B%5D=identifier&fl%5B%5D=title&rows=50&output=json)
- **Fujitsu**: "A fully compliant PL/S compiler was developed by Fujitsu Ltd in the late-1970s, using IBM's PL/I Optimizer compiler source code as a starting point", used internally and by affiliates; phase prefix "I" replaced by "J"; IBM copyright notices deleted (Wikipedia). It belongs to the IBM–Fujitsu software dispute of the 1980s. — [Wikipedia](https://en.wikipedia.org/wiki/IBM_PL/S)
- **pls-split** by J. Morrison (cbttape.org/~jmorrison; the full name is not on the page), public domain, 4 KB Perl. It "split[s] IBM MVS38j PL/S source code into PL/S and S/370 assembler source". The heuristic from the script header: "This code asserts '*' in column 1 means PL/S, else it's assembler; of course, that's not always the case". It handles GENERATE blocks and drops the "START/END UNREFERENCED COMPONENTS" blocks. — [index page](https://cbttape.org/~jmorrison/mvs38j/index.html); [script](https://cbttape.org/~jmorrison/mvs38j/pls-split)
- **ZDoc** (GitHub, org IBM-SUMMER-PRACTICE-2026, MIT license, created 2026-07-02, 3 stars): "the only actively maintained OSS doc generator for PL/X, PLAS, and mainframe Assembler". It generates documentation and is not a compiler. — [GitHub ZDoc](https://github.com/IBM-SUMMER-PRACTICE-2026/ZDoc)
- **OS2World APP-EDITOR-Alpha**: an old OS/2 editor with syntax highlighting for "370 and 386 assembler, PASCAL, C, PL/X, FORTRAN". — [GitHub](https://github.com/OS2World/APP-EDITOR-Alpha)
- GitHub repository searches ("PL/S compiler", "PL/S" in description or readme, "pls mvs") returned no PL/S compiler, parser or translator. The nearest work is Zaneham's PL/I F tooling: `IBM-system360-LSP` (COBOL F and PL/I F LSP, Apache-2.0) and a clean-room PL/I F parser. — [GitHub Zaneham/IBM-system360-LSP](https://github.com/Zaneham/IBM-system360-LSP)
- CBT tape web search: nothing PL/S-specific beyond Morrison's MVS 3.8J page. — [cbttape mvs38j](https://cbttape.org/~jmorrison/mvs38j/index.html)
- PL/X availability to ISVs: a search summary claims IBM offered the PL/* languages to selected customers or ISVs through a "Developer Partner program", but I found no primary IBM source. **Unverified.**

### Inferences
- RL/S is the strongest precedent: three people built a working PL/S II compiler from public documents and MVS source, which is the situation this project is in. Its manual is the most complete grammar and semantics description available. As a Rand-copyrighted work it can be read as a reference, but its text should not be copied.
- No hits for a decompiler or "PL/S reconstruction" tool. Because the PL/S II listings keep the source as `*` comments, reconstruction needs no decompiler: pls-split already pulls it out roughly. A more robust extractor that also pairs each statement with its generated code would be the natural first tool (my inference).
- The task mentioned "Dave Kreiss MACCVT"; no trace of it was found (see Gaps).

### Gaps
- No trace found of "Dave Kreiss MACCVT" or of any Greg Price PL/S tooling. They may sit in groups.io archives (hercules-390, H390-MVS), which need a login and were not searched.
- Status of the RL/S compiler source (Rand archives, David J. Smith personally): unknown. Asking the uploader could be worthwhile.
- groups.io and IBM-MAIN discussions of PL/S compilers: not reached (Google Groups 429, groups.io login).

## 3. Was PL/S source itself distributed (tapes, microfiche, macros)? The corpus question

### Takeaway
IBM published PL/S programs only as compiled assembler listings: the IBM-internal LY/SY microfiche, whose catalogue abstracts say they include "the PL/S source used to generate these listings" (section 1), and on MVS 3.8j the source modules whose PL/S statements are kept as comments. The PL/S half of the MVS 3.8j "bilingual" macros is real PL/S source. A count over the maintainer's MVSCE DLIB copies finds about 360 bilingual macros and 321 PL/S-compiled source modules.

### Cited Findings
- "Programs written by IBM in PL/S II are documented by means of listings in microfiche form"; "*These listings are placed on microfiche." — [GC28-6794-0](https://bitsavers.org/pdf/ibm/360/pls/GC28-6794-0_PLSIIguideMay74.pdf)
- Rand built RL/S from "PL/S source and generated assembler code examples from IBM distributed source files for the MVS operating system". This confirms that the MVS distribution served as the corpus as early as 1975–77. — [Wikipedia](https://en.wikipedia.org/wiki/IBM_PL/S)
- Local measurement (2026-10-12, `grep` over `/Users/mike/repos/mvs/mvs38src`): **321 files** carry a PL/S IDR `(C'PL/S…')`. The id/version pairs (the trailing date field stripped) are: `PL/S-II,0502` ×210, `PL/S-II,0503` ×52, `PL/S-II,0402` ×32, `PL/S,1400` ×23. In `/Users/mike/repos/mvs/mvs38-ibmsrc` there are 84 files. The sibling note has the fuller IDR analysis. (My own measurement, no URL.)
- Local measurement over the bilingual macros in `/Users/mike/repos/mvs/mvs38src/work/macros/mvsce-2.1.4-dlib/`: macros with the `*%GOTO label; /*` / `*%label : ;` bilingual pattern: AMACLIB 92 of 567, AMODGEN 89 of 289, APVTMACS 128 of 243, ATSOMAC 44 of 101, ATCAMMAC 9 of 140. That is **362 in all** (a lower bound from a simple regex, possibly with duplicates across libraries). Example: IHAASCB starts `*        %GOTO ASCBL1;  /*` / `MACRO` / `IHAASCB &DSECT=YES */` / `*%ASCBL1 : ;` and documents "PL/S - DCL ASCBPTR PTR". (My own measurement.)

### Inferences
- The two local sets of files make a large real-world test suite. The macros contribute PL/S DECLARE structures (control-block maps) in compile-time `%` macro syntax. The source modules contribute paired PL/S statements and IBM-generated code, enough to check a new compiler statement by statement.

### Gaps
- Whether OS/360 or MVS optional-source tapes or microfiche ever carried the pure PL/S source, i.e. separate "PLS" members: no evidence either way.
- The regex counts above were not cross-checked by hand for false positives or duplicates.
